PhD research

Machine Learning for Atmospheric Data

My PhD at UNIST (IRIS Lab, 2023–present) is a long-running, large-scale ML project. The application is atmospheric monitoring; the skills transfer to any messy, multi-source dataset.

Problem
Satellite measurements carry systematic errors and leave large gaps where clouds or orbits block the view, which limits downstream emission estimates.
Approach
Gradient-boosted models with staged feature selection correct each source; the sources are harmonized and fused into one daily dataset; spatio-temporal deep learning (Mamba / state-space, KAN) fills the gaps; the improved data feeds emission inversion.
Validation
Group-wise hold-outs: whole sites, months and years left out, so scores reflect real generalization rather than memorization.
Result
0.81R², withheld sites
10.78RMSE (ppb)
2026first-author paper
