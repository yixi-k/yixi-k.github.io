# yixi-k.github.io

Personal website of **Jebun Naher Keya**, PhD candidate at UNIST working on machine learning for satellite Earth observation: global methane mapping, atmospheric composition and precipitation nowcasting.

Live at **https://yixi-k.github.io**

The site is a single static `index.html` (HTML, CSS and vanilla JavaScript, no build step), served by GitHub Pages from the `main` branch. The previous al-folio template is kept on the `al-folio-backup` branch.
